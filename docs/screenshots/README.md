# Скриншоты

Каталог для изображений, на которые ссылается `README.md` (раздел «Скриншоты»). Сейчас снимков нет: намеренно не публикуются ни реальные кадры, ни нарисованные макеты.

## Как сделать снимок

1. В сборках **1.0.3 и новее** скриншоты разрешены по умолчанию — снимайте штатными средствами Android.
2. Если защита включена (переключатель **Настройки → Приватность экрана → «Разрешить скриншоты и превью в недавних»** выключен), система не даст снять окно и скроет содержимое в недавних приложениях. Настройка применяется сразу, без перезапуска.
3. В APK **1.0.2 и старше** окно защищено флагом `FLAG_SECURE` постоянно: снимков не будет, это не баг.
4. Публикуйте только пустые или вымышленные чаты. Не выкладывайте настоящую переписку, API-ключи, заголовки провайдеров, названия моделей и статистику расходов.

## Правила оформления

| Параметр | Значение |
|---|---|
| Формат | PNG, без сжатия с потерями |
| Имя файла | `chat-dark.png`, `chat-light.png`, `chat-amoled.png`, `providers.png`, `statistics.png`, `settings.png` |
| Планшет | отдельный кадр с суффиксом `-tablet` |
| Вес | до ~500 КБ на кадр, иначе README грузится медленно |

Ссылки в README добавляются обычным markdown: `![Чат, тёмная тема](docs/screenshots/chat-dark.png)`.
