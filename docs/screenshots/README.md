# Скриншоты

Каталог для изображений, на которые ссылается `README.md` (раздел «Скриншоты»). Сейчас снимков нет: намеренно не публикуются ни реальные кадры, ни нарисованные макеты.

## Как сделать снимок

1. В релизных APK **1.0.2 и старше** окно постоянно защищено `FLAG_SECURE`, поэтому система не даёт снять экран и не показывает содержимое в недавних приложениях.
2. В сборках из `main` защита стала настройкой: **Настройки → Приватность экрана → «Разрешить скриншоты и превью в недавних»**. По умолчанию выключено, применяется сразу, без перезапуска.
3. Снимайте debug-сборку и пустые или вымышленные чаты. Не публикуйте настоящую переписку, API-ключи, заголовки провайдеров и статистику расходов.

## Правила оформления

| Параметр | Значение |
|---|---|
| Формат | PNG, без сжатия с потерями |
| Имя файла | `chat-dark.png`, `chat-light.png`, `providers.png`, `statistics.png`, `settings-amoled.png` |
| Ширина | телефон — как есть; планшет — отдельный кадр с суффиксом `-tablet` |
| Вес | до ~500 КБ на кадр, иначе README грузится медленно |

Ссылки в README добавляются обычным markdown: `![Чат, тёмная тема](docs/screenshots/chat-dark.png)`.
